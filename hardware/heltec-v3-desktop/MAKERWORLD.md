## Description

```
A clean, printable enclosure for the Heltec WiFi LoRa 32 V3 running Meshtastic — designed to sit on a desk as a permanent indoor node.

Holds a 1000mAh LiPo for brief power backup, has a latching power switch on the outside, and a clean SMA antenna passthrough. No frills, no fuss.

---

What's included:
- Body, tray, and lid STLs
- Full build guide with wiring notes
- Bill of materials with sourcing links
- Meshtastic firmware config notes

---

Hardware needed:
- Heltec WiFi LoRa 32 V3
- 1000mAh 3.7V LiPo with JST connector
- SMA pigtail or antenna
- Latching panel-mount switch
- M3 heat set inserts (×4) + M3×8 screws (×4)

---

Print settings:
- Material: PETG (recommended) or PLA
- Layer height: 0.2mm
- Walls: 3
- Infill: 15–20%
- Supports: Not required

---

Button access: The V3 has RST and PRG buttons. In normal Meshtastic use you rarely need them,
so instead of plungers there are small holes — poke through with a pin, toothpick, or pen if needed.

---

Part of an open-source enclosure library for Meshtastic nodes.
More board variants and outdoor/solar configs coming. GitHub link in profile.
```
